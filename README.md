# Inventory Management System

A terminal-based Inventory Management System built using Python and PostgreSQL.

## Features

- Category management
- Supplier management
- Product management
- Purchase management
- Sales management
- Stock tracking
- Low-stock alerts
- Sales reports
- Inventory reports
- Supplier reports

## Technologies

- Python
- PostgreSQL
- Psycopg 3
- SQL
- Git
- VS Code

## Database

The system uses a normalized relational database containing:

- categories
- suppliers
- products
- purchases
- purchase_items
- sales
- sale_items

## Python Concepts

- Functions
- Modules
- Exception handling
- Object-oriented concepts where applicable
- Database connectivity
- Transactions
- SQL joins
